# ACS Calvert website

The bilingual (English/Spanish) website for **ACS Calvert, the American Cooperative School of La Paz, Bolivia**. Built from two briefs: `MASTER_PROMPT.md` (school research, strategy and verified facts) and the premium school-website master prompt (design system, motion, architecture).

## Stack

- Next.js 15 (App Router, static generation), React 19, TypeScript strict
- Tailwind CSS v4 (`@theme` tokens in `src/app/globals.css`)
- GSAP + ScrollTrigger (scroll choreography), framer-motion (menus, drawers)
- Radix Dialog + cmdk (⌘K / Ctrl+K command palette)
- react-hook-form + zod (one schema shared by the inquiry form and API)
- date-fns (EN/ES locales), lucide-react
- @vercel/blob for staff edits and inquiries (falls back to `.data/*.json` locally)
- @anthropic-ai/sdk for **Kantuta**, the AI receptionist

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run lint
npm run build && npm start
```

QA script (Playwright; checks every route in both languages at 390/768/1440px, the inquiry API, the assistant and the form):

```bash
ADMIN_USERNAME=staff ADMIN_PASSWORD=change-me-123 node tests/qa.mjs http://localhost:3000
```

## Staff admin (`/admin`)

1. In Vercel, add a **Blob** store to the project (sets `BLOB_READ_WRITE_TOKEN`).
2. Set `ADMIN_USERNAME` and `ADMIN_PASSWORD` (8+ characters). Redeploy.
3. Sign in at `/admin`. Sessions are httpOnly HMAC-signed cookies valid 12 hours; changing either credential signs everyone out; writes must be same-origin.

The editor lists collections (home copy, hero slides, stats, news, events, mission, values, leadership, admissions steps and FAQ, facilities, programs, careers). Edits are stored per collection in Blob (`acs-calvert/content-overrides.json`), merged in place onto the data objects on the server and in the browser, and saving revalidates the site. **Reset** restores the default. Inquiries are listed at `/admin/inquiries`. Photo fields are pickers over the photo library; new photos are added to `public/images/acs/` and `src/data/media.ts`.

## Kantuta, the AI receptionist

Named after Bolivia's national flower and the school's street (Pasaje Kantutas). **[[CONFIRM]]** the name with the school.

- Set `ANTHROPIC_API_KEY` to enable live answers (Claude Opus 5.5, low effort, cached system prompt, server-side refusal fallback). Without it, answers come from the keyword FAQ in `src/lib/assistant/offline.ts`.
- Grounded only in the site's data (`src/lib/assistant/knowledge.ts`); `[[CONFIRM]]` facts are stripped so it never repeats them. Never quotes tuition. Replies in the family's language; links on-site paths, emails and phones.
- Limits: 30 messages / 10 minutes per IP, last 12 turns, 1,500 characters per message.
